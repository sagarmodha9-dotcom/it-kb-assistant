# Request Software or Access

Applies to: all staff. Owner: Service Desk.

## Software available in Company Portal
Many approved apps (for example Adobe Acrobat Reader, Zoom, Visual Studio Code, Notepad++) can be installed right away from the Company Portal app without a ticket.

## Software not in Company Portal
Submit a software and access request in the IT portal at https://it.example.org/request. Include the software name, business reason, and cost center.
- Free software: approved by your manager.
- Paid software: approved by your manager and the software licensing team. Allow 5 business days.

## Access requests
Use the same form to request access to shared drives, shared mailboxes, or applications. The data owner must approve. Access is reviewed every 90 days and removed if no longer needed.

## Admin rights
Local administrator rights are not granted to standard users. If an install requires admin rights, the Service Desk will install it remotely after approval.
