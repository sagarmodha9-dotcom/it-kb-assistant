# New Hire Laptop Setup

Applies to: new employees and their managers. Owner: Endpoint team.

## Before day one
Managers must submit the new hire request at least 5 business days before the start date. Laptops are pre-registered with Windows Autopilot, so the new hire only needs to sign in.

## First sign-in
1. Connect to Wi-Fi (Example-Guest is fine for setup) or plug into a wired port.
2. Sign in with the work email and the temporary password from the welcome email.
3. Autopilot installs required apps. This takes about 45 minutes; keep the laptop plugged in.
4. Set up MFA when prompted (see Set Up MFA on a New Phone).
5. Change the temporary password (see Reset or Change Your Password).

## Standard software
Microsoft 365 apps, Teams, GlobalProtect VPN, CrowdStrike Falcon, and the Company Portal app. Other software is requested through Company Portal or a software and access request.

## Returning equipment
When an employee leaves, the manager returns the laptop and charger to IT within 5 business days.
