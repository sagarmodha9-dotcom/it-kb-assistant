# Shared Mailboxes in Outlook

Applies to: Microsoft 365 users. Owner: Messaging team.

## Getting access
Shared mailbox access must be approved by the mailbox owner. Submit a software and access request with the mailbox address and the owner's name. Access is granted within 1 business day after approval.

## Seeing the mailbox in Outlook
After access is granted, the mailbox appears automatically in Outlook within 60 minutes. Restart Outlook if it does not appear.
In Outlook on the web, right-click "Folders", choose "Add shared folder or mailbox", and enter the mailbox address.

## Sending as the shared mailbox
In a new message, select From and choose the shared mailbox address. If "From" is not visible, open Options and select "Show From".

## Common problems
- Mailbox missing after 60 minutes: confirm the request was approved, then restart Outlook.
- Sent items going to your personal Sent folder: this is expected in new Outlook; the shared mailbox copy is saved automatically.
