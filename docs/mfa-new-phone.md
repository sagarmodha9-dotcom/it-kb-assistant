# Set Up MFA on a New Phone

Applies to: all staff using Microsoft Authenticator. Owner: Service Desk.

## Before you start
You need your old phone OR a temporary access pass (TAP) from the Service Desk. A TAP is a one-time code valid for 8 hours.

## Steps (you still have your old phone)
1. On a computer, go to https://mysignins.microsoft.com/security-info and sign in.
2. Select "Add sign-in method", choose "Authenticator app", and scan the QR code with Microsoft Authenticator on the new phone.
3. Approve the test notification on the new phone.
4. Set the new phone as the default sign-in method.
5. Delete the old phone from the list.

## Steps (old phone lost, reset, or broken)
1. Call the Service Desk at extension 4357. The technician verifies your identity by calling you back on the phone number in your HR record, or by confirming with your manager on Teams; a name and employee ID alone are not enough.
2. The Service Desk issues a temporary access pass (TAP).
3. Sign in at https://mysignins.microsoft.com/security-info with the TAP and register the new phone.

## Notes
- Never approve an MFA prompt you did not start. Report unexpected prompts as a security incident (see Report Phishing and Suspicious Activity).
- SMS codes are not allowed as a primary method.
